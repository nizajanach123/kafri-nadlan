# כפרי נדל"ן – אתר תדמית

אתר בעברית (RTL) בקובץ אחד: `index.html`. הוא כולל את כל העיצוב, התמונות והסקריפטים, ואפשר לפתוח אותו ישירות בדפדפן.

## מבנה התיקייה
- `index.html` – האתר עצמו (זה הקובץ שמעלים ל-Netlify).
- `src/` – קוד סרגל הניווט (React/TSX). `build-embed.ps1` משבץ אותו בתוך `index.html`.
- `serve.ps1` – שרת מקומי לתצוגה מקדימה (פורט 5173).
- `_parts/` – חלקי תוכן ועזרים ששימשו לבניית העמודים.
- `promo.html`, `promo2.html` – סרטוני פרסום.
- שאר הקבצים – תמונות ולוגואים.

## הוספת פרויקט חדש
1. כרטיס חדש בתוך `<div class="pgrid">` באזור `#projects`.
2. בלוק `<div class="pview" id="view-שם-הפרויקט" hidden>` עם תוכן העמוד.
3. הכתובת של העמוד: `#/שם-הפרויקט`.

## פרסום
מעלים את `index.html` (ואת התמונות שלידו) ל-Netlify, או מחברים את המאגר ל-Netlify.
